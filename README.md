# Pip's Midnight Folio 🌙✨

An enchanting 2.5D interactive bedtime storybook and nocturnal nursery diorama built with TypeScript, HTML5 Canvas, and Web Audio API.

## Features
- **Interactive Claymorphic Nursery**: Multi-plane parallax, mascot state machine (5 moods), treat feeding, and soothing sound effects.
- **2.5D Lullaby Workshop Attic**: Device tilt & cursor diorama, playable 12-note golden music box, ambient dream lantern bloom, and rattle chimes.
- **Pop-Up Storybook**: Dual-page illustrated fairy tale spread with realistic page flips and poetry verses.
- **Starry Delivery Route Mini-Game**: Rooftop starlight flight catching stars, parcels, and moons with celestial Easter Egg unlocked at 500+ points!
- **Nocturnal Dream Wall & Guestbook**: Interactive dream-wish board with stardust counters.
- **Day & Night Themes**: Switch seamlessly between Creamy Peach Daylight and Celestial Midnight Stardust.

## Tech Stack
- **TypeScript & Vite**
- **Vanilla CSS3 Claymorphism & Glassmorphism**
- **HTML5 2D Canvas & Web Audio API**
- **Lenis Smooth Scrolling & Canvas Confetti**

## Deployment
Configured for zero-config Vercel deployment with Vite.
